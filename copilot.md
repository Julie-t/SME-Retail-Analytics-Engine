# Project Execution & Change Log (`copilot.md`)

## Project Context
- **Name**: Deterministic SME Retail Analytics Engine
- **Database**: DuckDB (`data/retail_engine.duckdb`)
- **Pipeline Architecture**: Medallion (Bronze -> Silver -> Gold via dbt)
- **Serving Layer**: Polars & FastAPI (<10ms target response time)
- **Primary Catalog Ingestion**: local Kaggle Sephora dataset ([nadyinky/sephora-products-and-skincare-reviews](https://www.kaggle.com/datasets/nadyinky/sephora-products-and-skincare-reviews)); The Beauty API loader is legacy-only.

---

## Technical Constraints & Guidelines
1. **Zero Hallucination Rule**: No mathematical operations or aggregations in the LLM. All math MUST be calculated deterministically in DuckDB/dbt or Polars.
2. **Data Standards**:
   - Staging (Bronze): Preserve and type verified source fields; do not infer transaction facts from product catalogues.
   - Intermediate (Silver): Normalize product identities and attributes; report source-backed quality diagnostics.
   - Marts (Gold): Deterministic catalogue and review-row metrics; sales, margin, inventory, and customer metrics require their own verified sources.
